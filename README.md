# ❤️ Heart Disease Scoring (FastAPI + Streamlit)

Учебный сервис для оценки сочетания медицинских признаков. API возвращает оценку модели и пояснение: стоит обсудить показатели с врачом, а результат ниже порога не исключает заболевание.

После EDA и сравнения восьми моделей выбрана CatBoost с ИМТ по AP на validation. Переобучение и сохранение модели — в [notebooks/heart.ipynb](notebooks/heart.ipynb), история экспериментов — в MLflow.

## Данные

Данные собраны из официальных файлов [NHANES (CDC)](https://wwwn.cdc.gov/nchs/nhanes/): циклы 2011–2012, 2013–2014, 2015–2016, 2017–2018 и 2021–2023. В `data/heart.csv` — 28 270 участников 20–79 лет с известной целевой меткой. Пропуски в признаках сохранены; синтетические строки не добавлялись.

`cardio=1` — участник сообщил, что врач когда-либо диагностировал хотя бы одно из пяти состояний: сердечную недостаточность, ишемическую болезнь сердца, стенокардию, инфаркт или инсульт (`MCQ160B–F`). `cardio=0` — ответы «нет» на все пять вопросов. Остальные случаи без определённой метки исключены. Это история диагнозов со слов участника, а не прогноз будущего заболевания.

`age` записан в приблизительных днях и переводится в годы в ноутбуке; `gluc` — категория **HbA1c**: 1 — <5.7%, 2 — 5.7–<6.5%, 3 — ≥6.5%. `cholesterol` — категория общего холестерина: <200, от 200 до <240 и ≥240 мг/дл. Давление усредняется по допустимым парным измерениям. Невалидные измерения заменяются пропусками.

Описание исходных переменных: [диагнозы](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2017/DataFiles/MCQ_J.htm), [HbA1c](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2017/DataFiles/GHB_J.htm). Веса обследования NHANES не используются: доли в этом датасете не являются оценками распространённости заболеваний среди населения США.

## Как читать ответ

`POST /predict` возвращает оценку `score`, рабочий порог `threshold`, результат сравнения `above_threshold` и пояснение `recommendation`.

`above_threshold=true`, если `score >= threshold`. Результат выше порога — повод обсудить показатели с врачом; результат ниже порога не исключает заболевание. `score` нельзя интерпретировать как процент личного риска.

В `imputed_fields` перечислены заполненные пропуски, в `test_metrics` — метрики на тестовой выборке, в `notice` — ограничения модели.

## Признаки и кодировки

|Поле|Описание и значения|
|-|-|
|`id`|Идентификатор участника в CSV. Не используется моделью и не передаётся в API|
|`age`|В CSV — приблизительный возраст в днях. API принимает возраст в годах: 20–79 полных лет|
|`gender`|1 — женский, 2 — мужской|
|`height`|Рост, см|
|`weight`|Вес, кг|
|`ap_hi`|Систолическое, или верхнее давление, мм рт. ст.|
|`ap_lo`|Диастолическое, или нижнее давление, мм рт. ст.|
|`cholesterol`|Общий холестерин: 1 — <200, 2 — от 200 до <240, 3 — ≥240 мг/дл|
|`gluc`|HbA1c: 1 — <5.7%, 2 — от 5.7% до <6.5%, 3 — ≥6.5%. Это не уровень глюкозы|
|`smoke`|Текущее курение: 0 — нет, 1 — да|
|`alco`|Употребление алкоголя за последние 12 месяцев: 0 — нет, 1 — да|
|`active`|Досуговая физическая активность: 0 — нет, 1 — есть|
|`cardio`|Целевая метка: 1 — ответ «да» хотя бы на один вопрос MCQ160B–F, 0 — «нет» на все пять. В API не передаётся|

Возраст и пол обязательны. Неизвестные остальные значения можно не передавать или указывать как `null`. Давление передаётся парой: оба значения либо ни одного; верхнее должно быть выше нижнего. Рост и вес также указываются вместе либо оба пропускаются.

Числовые пропуски заполняются медианами train, `smoke` и `active` — модами train. Для неизвестных `cholesterol`, `gluc` и `alco` внутри предобработки используется категория `-1`; передавать её в API не нужно. ИМТ (`bmi`) рассчитывается автоматически из роста и веса.

## Эксперимент

Сравнены восемь моделей на одинаковом разбиении train/validation/test примерно 70/15/15. Одинаковые исходные профили сгруппированы при разбиении. По Average Precision на validation выбрана CatBoost с ИМТ: 12 признаков, AP = 0.302.

Порог около **0.092** подобран на validation по максимальному MCC при условии Recall ≥ 0.65.

Результаты на test:

|ROC-AUC|AP|Recall|Precision|F2|
|-|-|-|-|-|
|0.803|0.306|0.752|0.219|0.505|

Обнаружено **309 из 411** положительных случаев, **102 пропущены**. Получено **1 105 ложноположительных ответов**. Модель выделяет часть положительных случаев, но даёт много ложных срабатываний. Результаты относятся к тестовой части этого датасета.
